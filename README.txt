FREE HOSTING:
1. Create a free GitHub account.
2. Create a new repository, e.g. khushu.
3. Upload index.html and the images folder.
4. Settings -> Pages -> Deploy from main branch -> / (root).
5. GitHub gives you a free github.io link.
